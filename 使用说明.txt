工具箱 3.3.0 · 网络服务 / 串口助手 / 网络调试 / ADB

运行：先执行 build.cmd，再双击 bin/Toolbox.exe，无需安装。适用于已启用 .NET Framework 4.8 的 Windows 10/11。
也可从 https://github.com/mazhujie/toolbox/releases/latest 下载完整便携 ZIP，整体解压后运行 Toolbox.exe。
便携 ZIP 包含 Platform Tools，无需另装 ADB；实时抓包需要单独安装 Npcap。

导航
- 左侧上方：网络服务、串口助手、网络调试、ADB 工具四个独立大类。
- 中间：当前大类的功能页；下方：当前页的操作按钮。
- 网络服务包含下载测速、出口 IP / 风险。
- 串口助手的参数设置与收发合并在同一页；高级参数可展开或收起。
- 网络调试包含 TCP / UDP 收发、局域网扫描（Ping）和实时抓包；连接与抓包独立运行。
- ADB 工具包含 Shell 命令和文件传输，两页共用 ADB 程序路径和设备选择。
- 左下角不显示状态。串口连接状态显示在串口页面右上角，切换页面保持连接。

下载测速
1. 选择国内阿里云 / 华为云镜像、中科大测速网、南京大学测速网，或海外 Cloudflare / OVH。
   也可粘贴 HTTP/HTTPS 直接下载文件地址。
2. 选择连接方式：
   - 直连：禁用程序自身的 HTTP 代理。
   - 系统代理：跟随 Windows Internet 代理设置，具体请求可能按系统规则绕过代理。
   - 手动代理：填写 http://127.0.0.1:7890，端口以代理软件显示的 HTTP 或混合端口为准。
     当前版本不支持纯 SOCKS5、HTTPS 代理入口和代理账号密码。
3. 设置下载时长（3–60 秒）和并发连接数（1–8），点击开始测速。
4. 可停止测试；下载阶段停止后显示已下载部分的平均值。取消延迟测量不产生记录。
5. 点击导出 CSV，保存本次运行的测速记录。关闭程序后不保留历史。

局域网扫描
1. 从左侧进入“网络调试 → 局域网扫描”页，选择网卡。程序根据该网卡的 IPv4 地址和实际掩码带入网段，
   优先选择有 IPv4 网关的可用网卡。网卡列表用于带入范围，不强制绑定发包网卡。
2. 可手动填写 CIDR（192.168.50.0/24）、完整起止地址（192.168.50.1-192.168.50.254），
   或单个 IPv4（192.168.50.1）。一次最多 65,536 个地址，目前不扫描 IPv6。
3. 默认超时 800ms、32 个并发、失败时最多尝试 2 次；收到成功回复后不再重复该 IP。
4. 点击“开始扫描”，每个 IP 都有一个点，返回结果后实时变色：
   - 绿色：延迟小于 10ms。
   - 黄色：延迟大于等于 10ms、小于 50ms。
   - 红色：延迟大于等于 50ms。
   - 灰色实心：已完成尝试，但没有收到成功的 ICMP Echo Reply。
   - 空心：尚未完成扫描。停止后剩余 IP 仍保持空心，不会误标为未响应。
5. “绿 < ms”和“黄 < ms”可调整分类阈值，已有结果会立即重新着色，不会重新发包。
6. 悬停或单击某个点，可查看完整 IP、延迟、尝试次数和状态。小于 1ms 的响应显示为 <1ms。
7. 每页最多 256 个 IP，可用上一页/下一页浏览更大网段。扫描进度和数量统计覆盖整个范围。
8. 可随时停止；程序停止派发新请求，并等待当前正在进行的 Ping 返回或超时。
   完成或停止后，可导出 CSV，包含全部目标 IP、分类、延迟、尝试次数、状态与响应地址。

扫描说明
- CIDR 网段自动跳过网络地址与广播地址（例如 /24 扫描 .1–.254）；/31 的两个地址及 /32
  单地址均保留。手动起止范围按输入逐个扫描。
- 默认绿色/黄色/红色阈值是可调整的显示规则，不是网络质量的统一标准。
- 未响应不等于离线。设备可能禁用 ICMP、被防火墙拦截、暂时丢包，或当前路由不可达。
- 此页只发 ICMP Ping，不扫描端口。发包走 Windows 系统路由，不使用测速页的 HTTP 代理；
  VPN、TUN 及其他路由设置仍可能影响实际路径。
- 测速、IP 查询、局域网扫描互斥运行，避免互相影响。
- 关闭程序不保留扫描历史。

出口 IP 与 IP 纯净度参考
1. 从左侧进入“网络服务 → 出口 IP / 风险”，默认使用系统代理。
2. 点击左侧“连接方式”按钮，可选系统代理、直连或手动代理。选择手动代理后，
   在本页顶部填写 HTTP / 混合端口地址，再点击“查询出口 IP”。
   此页设置与下载测速页独立，不用跳页修改，也不会改动 Windows 系统代理设置。
3. 左侧显示禁用 HTTP 代理的出口；右侧显示你选定的系统或手动代理出口。
   如果改为直连，本次只查询左侧。系统代理可能按 Windows 规则绕过部分地址。
4. 可查看公网 IP、归属地、运营商、ASN，以及 Scamalytics 网页的风险分、风险等级、
   机房、VPN、代理、Tor 和外部黑名单标签。风险分直接使用网页上的 Fraud Score，
   范围 0–100，越高风险越高，不转换成“纯净百分比”。
5. 可选中文字复制结果。修改代理设置后，右侧结果会清空，需重新查询。

如何理解 IP 信息
- Scamalytics 的风险分和网页标签仅供参考。低分、0 分、未标记均不保证“绝对纯净”，
  也不代表其他网站一定允许访问；本工具不查询所有黑名单，不承诺风控或解锁结果。
- 程序先从 IPQuery 取得出口 IP 和归属地，再查询 Scamalytics 对应 IP 的公开报告页。
  IPQuery 返回的风险分和风险标签会被忽略，界面明确区分这两个数据来源。
- 数据缺失、网页验证、限流、页面格式变化或查询失败时，Scamalytics 风险显示“未知”，
  不会当成 0 分，也不会悄悄改用 IPQuery 分数；已获取的出口 IP 仍会显示。
- IPQuery 失败时会尝试 ipify 仅查询 IP，取得 IP 后仍会查询 Scamalytics。
  归属地可能不可用；备用请求和风险查询均使用原来选定的直连或代理设置。
- 当前使用 Scamalytics 公开网页，不需要填写 API Key；它不是 Scamalytics 官方 API。
  每次会核对报告标题中的 IP 与待查 IP 一致，并只读取实际显示的 Fraud Score。
- 结果是 IP 查询服务看到的公网出口。浏览器、测速地址和不同网站可能因为分流规则
  使用不同出口。系统代理也可能绕过某些地址。
- TUN、VPN、透明代理可能接管“直连”流量。本程序无法据此取得被 TUN 隐藏的运营商出口。
- 两路 IP 相同不一定表示代理失效；也可能是共同出口、分流规则或 TUN 接管。
  返回 IPv4/IPv6 不同时会提示不能直接比较。
- 只在点击查询时联网；测速、IP 查询与局域网扫描互斥，避免互相干扰。可停止查询。
- 查询会连接 IPQuery、Scamalytics；必要时使用 ipify。第三方会收到连接的出口 IP，
  Scamalytics 也会收到待查询的 IP。服务可能限流或更新页面；程序不会自动循环重试。
- IP 查询结果仅留在本次窗口，不自动写入日志，不包含在测速 CSV 中。
- 风险分来源：https://scamalytics.com/ip
  IP 与归属地接口说明：https://ipquery.io/developers/api
  备用 IP 服务：https://www.ipify.org/

如何比较国内与代理
- 国内直连：国内地址 + 直连。
- 代理下载：海外地址 + 手动代理或系统代理。
- 对比同一条线路：同一个下载地址，分别选择直连和手动代理。
- 如果代理软件开了 TUN、VPN 或透明代理，程序的“直连”也可能被其接管。
- 手动模式向填写的 HTTP 代理发送请求；是否实际转发至远端节点仍取决于代理规则。

指标说明
- 大数字在下载中是最近约 250ms 的速度，结束后是整个下载阶段平均速度。
- Mbps 为兆比特/秒，MB/s 为十进制兆字节/秒；1 MB/s = 8 Mbps。
- 首字节延迟是三次独立 HTTP 请求收到第一个响应体字节所用时间的平均值，包含 DNS、
  建连、TLS、代理和服务器响应时间。不是 ICMP Ping；三次请求可能复用连接。
- 平均速度包含下载阶段连接开销，不包含前面的三次延迟测量。
- 下载流量按 HTTP 响应体字节统计，不含协议开销及延迟测量读取的数据。
- 文件较小时会重复请求直到时长结束；文件只读入内存缓冲区，不保存到磁盘。
- 预置镜像、大学测速站、Cloudflare 和 OVH 均为第三方服务，速度取决于网络、代理、服务器和限速；
  结果不保证等于宽带套餐上限。不可用时请切换地址。
- 此版本测下载和 HTTP 首字节延迟，不测上传、ICMP 丢包率，也不自动切换代理节点。
- 测速会实际下载数据并消耗流量，请根据需要调低时长和并发数。

串口助手
1. 进入“串口助手 → 串口收发”，在顶部选择 COM 端口和波特率。
   插入设备后点击左侧“刷新端口”；未选择端口时连接按钮不可用。
2. 默认 115200、8N1（8 数据位、无校验、1 停止位）、无流控。
   点击“高级参数”可修改数据位、校验、停止位、流控、DTR/RTS，收起后保留设置。
   使用 RTS 硬件流控时，RTS 由驱动控制，单独的 RTS 开关不可用。
3. 点击左侧“连接串口”；连接后该按钮变为“断开串口”，连接参数锁定。
   右上角显示端口、波特率和数据格式，断开后可修改参数并重新连接。
4. 发送区可切换“单条发送”和“多条发送”。文本发送支持 UTF-8、GBK、ASCII，可添加 CRLF / LF / CR；HEX 发送支持
   AA BB 0D 0A、AABB0D0A 或 0xAA 0xBB，不自动添加文本结尾。
5. 单条模式输入内容后点击“发送一次”，或设置发送间隔（100ms–1小时）后定时发送。
   多条模式可新增、删除条目，每条有独立的发送勾选框与 HEX 开关。
   “发送选中条目”按列表顺序发送一轮；“开始循环发送”按间隔逐条发送，末尾返回首条。
   文本条目使用页面编码和结尾，HEX 条目不追加结尾。未勾选的条目不会发送。
   发送前一次性校验全部选中内容，某条无效时整轮不发送，并提示条目编号。
   发送期间锁定内容和选项；可用左侧按钮停止。断开串口或退出程序也会停止剩余条目。
   已开始的串口写入会继续完成，停止不撤回已经发出的字节；不叠加并发写入。
   列表最多 1,000 条，所选内容总量最多 1 MB；当前窗口关闭后不自动保存列表。
6. 接收区支持时间戳、HEX 显示、显示/隐藏发送记录、自动滚动和 RX/TX 字节计数。
7. “清空记录”同时清空显示记录、待显示的接收数据和累计 RX/TX 字节数，后续数据从零重新计数。
   清空不会断开串口、停止发送或修改发送内容；“保存日志”导出当前显示的文本。
8. 切换到网络服务页仍保持串口连接、接收和已启动的定时发送；关闭串口、设备报错或
   退出程序会停止定时发送。程序启动不会自动打开端口或发送数据。

串口说明
- 每次最多发送 65,536 字节；显示历史最多约 256 KB / 4,000 条，较早记录会被裁剪。
  接收显示队列最多 1 MB，队列溢出会明确提示。日志是当前显示记录，不是无限录制。
- 设备忙、驱动错误、非法参数、发送超时等错误会显示在页面；通信错误后关闭连接，
  可处理设备问题后重新打开。波特率等参数是否可用取决于设备驱动。
- 当前提供通用串口收发，不包含 Modbus 等协议解析、自动校验码、波形或文件传输。
- 本版已用模拟串口验证文本/HEX 收发、定时发送、断开重连、页面切换和退出释放。
  尚未连接真实串口设备；请使用与你设备一致的参数进行实际通信验证。
- 串口预览中的 COM99 为模拟端口；preview-serial-demo.png 使用模拟回环数据，
  截图中的连接不是实际硬件。preview-serial-advanced.png 展示高级参数展开状态。

网络调试（独立大类）
1. 从左侧进入“网络调试 → TCP / UDP 收发”，选择 UDP、TCP 客户端或 TCP 服务端。
2. 选择本地 IPv4 和端口。0.0.0.0 监听所有本机 IPv4 地址，端口 0 由系统自动分配。
3. UDP：打开后填写目标 IPv4/主机名与端口，可发送文本或 HEX；每次发送一个数据报。
   TCP 客户端：填写目标服务器与端口后连接。TCP 服务端：开始监听后选择一个已接入
   的客户端发送，或选择“全部客户端”逐个发送。最多接入 64 个 TCP 客户端。
4. 支持 UTF-8、ASCII、GBK，发送结尾可选无/CRLF/LF/CR。HEX 模式不附加文本结尾。
   开启“解析转义符”支持 \\、\r、\n、\t、\0，其他转义会报错；原始字节请用 HEX。
5. 可定时发送，启动时固定内容和目标，停止后可修改；前一次写入未完成时不积压发送。
6. 日志模式显示时间、RX/TX、对端与内容；关闭日志模式时只显示接收数据。
   “暂停显示”只冻结画面，接收和计数继续；恢复后显示保留的最近记录。
7. “清空记录 / 计数”同时清空日志、待显示数据及 RX/TX，后续数据重新计数。
   “保存日志”导出当前保留的数据日志。“载入文件为 HEX”只填入发送区，不自动发送。
8. TCP 服务端可断开所选客户端；选中“全部客户端”时会断开全部客户端，监听继续。
   关闭连接或退出程序释放当前 Socket；切换页面仍保持连接与收发。

网络调试说明
- 该页为普通 IPv4 Socket，不使用 HTTP 代理，不提供 TLS、代理握手或 IPv6。
- TCP 是字节流，读取分段不代表消息边界；不同 TCP 客户端分别进行文本解码。
- UDP 单次数据报最多 65,507 字节，TCP 单次写入最多 65,536 字节，文件载入同样限额。
- TCP 群发失败会停止后续目标，先前已成功发送的字节不会撤回；详情查看每个对端的 TX 日志。
- 日志上限约 256 KB / 4,000 条，显示队列上限约 1 MB / 4,000 条；显示丢弃会明确提示，
  字节计数仍统计收到的数据。此版本提供日志导出，不包含接收数据持续落盘或自动校验码。
- 网络调试预览使用真实本机回环测试数据；未连接截图中的外部设备。

实时抓包
1. 从“网络调试 → 实时抓包”进入。先安装 https://npcap.com/#download 提供的 Npcap，
   点击左侧“刷新网卡”，选择网卡后点“开始抓包”。程序启动或切页不会自动抓包。
   缺少驱动或权限不足时显示错误。Npcap 不放入便携 ZIP，也不影响其他工具使用。
   如果安装时限制仅管理员使用，请以管理员身份运行工具箱。
2. BPF 过滤可填 tcp、udp port 53、host 192.168.1.20 等，留空抓取所选网卡全部流量。
   混杂模式默认关闭；本机进程间流量请选择回环网卡。开始后锁定网卡、过滤式与保存设置。
3. 列表实时显示时间、源/目标、协议、原始长度和摘要，支持 Ethernet/VLAN、IPv4/IPv6、
   TCP、UDP、ICMP/ICMPv6 和 ARP；选中数据包查看 HEX / ASCII，最多预览前 4,096 字节。
   不提供 TCP 流重组、应用层分析或 TLS 解密；分片和截断会提示。
4. 自动保存到“文档/ToolboxCaptures”，可自行修改目录。每次生成唯一的 PCAP 文件，
   每包最多捕获 65,535 字节，超过时标明捕获长度。停止后可另存 PCAP 或打开抓包目录。
   文件可用 Wireshark 继续分析；列表保留范围不影响已经保存的数据。
5. 默认时长上限 60 秒、文件上限 64 MiB；可设置 1–3,600 秒及 1–512 MiB，任一达到即停止。
   列表仅保留最近 1,000 包 / 8 MiB，较早数据从列表移除但仍在 PCAP 文件中。
6. 暂停显示只冻结列表，抓包、计数和写入继续。切换页面保持抓包，停止或退出程序时
   等待本次任务结束并关闭文件，不影响其他程序的抓包会话。
7. “缓冲丢包”为 Npcap 返回的统计，不可用显示“—”，0 不保证物理链路没有丢包。
   抓包走所选网卡，不使用测速页的 HTTP 代理设置；实际可见流量取决于网卡、路由和权限。
8. 本版通过模拟数据验证解析、PCAP、界面、上限、取消和释放。开发机未检测到 Npcap，
   尚未完成真实网卡抓包验证。preview-capture-demo.png 为模拟数据预览。

ADB 工具
1. Release 便携 ZIP 已包含完整 Platform Tools 37.0.1，整体解压即可使用 ADB。
   单独运行自行编译的 EXE 时，从页面的官方下载链接获取 Windows Platform Tools，完整解压。
   可点击“选择…”找到 adb.exe，也可将完整 platform-tools 文件夹放在 Toolbox.exe 旁自动发现。
   不能只复制 adb.exe；需保留同目录 DLL。便携目录请整体复制，USB 调试和设备驱动仍需配置。
2. 点击“刷新设备”。USB 设备需开启 USB 调试并在设备上授权；离线或未授权会明确显示。
   有多台在线设备时手动选择，所有任务都明确指定所选设备，运行期间不能切换设备。
   刷新后原设备消失不会改选另一台。ADB 路径在刷新成功后记在本机，设备选择不跨窗口保存。
3. 网络设备输入 IP:端口后点击“连接设备”；网络 ADB 必须已启用，需要配对时先完成官方配对流程。
   “断开网络设备”仅断开当前所选的网络设备，不关闭 ADB 服务或其他连接。
4. Shell 页输入设备命令，点击“执行命令”或 Ctrl+Enter。支持多行、实时输出和退出码，保留本次窗口
   最近 30 条命令供选择。每次是独立 shell，不保留上一次 cd；可在一次输入中写多条命令。
   top、vi、交互输入等请用“打开交互终端”，退出该会话时在终端输入 exit 或关闭终端窗口。
5. 文件页“本地来源”选择或拖入一个文件/目录，填写完整设备目标路径，再点“推送到设备”。
   “设备来源”填写完整设备文件/目录路径，“保存目录”选择电脑目录，再点“拉取到电脑”。
   路径支持中文与空格，设备路径以 / 开头。目标存在时按 adb push/pull 规则覆盖；权限以设备为准。
   设备路径可点击旁边的“浏览…”选择：目录在前，文件在后，类型一栏明确区分文件、目录和链接。
   双击目录进入，可返回上一级、跳到根目录、显示隐藏项、筛选当前目录；地址栏回车前往，Tab 接受补全。
   推送时只能选择板端接收目录；拉取时可选择单个文件或整个文件夹，文件夹连同内部内容一起拉取。
   “使用当前目录”可选当前目录或空目录。选择后只填写路径，仍需点传输按钮才开始收发。
6. 传输显示 ADB 原始输出，不用固定超时中断大文件；可点击“停止当前任务”。
   两页共用一个内置任务，切页继续执行；停止或关闭工具箱会结束本工具启动的客户端，不执行 kill-server。
   取消可能留下部分文件，也不能保证设备端启动的程序已停止。外部交互终端需自行关闭。
7. 输出最多保留最近约 256K 字符，命令历史不自动写盘。“清空”只清空当前页输出；Shell 输出可手动保存。
   ADB 路径保存位置：%LOCALAPPDATA%\Toolbox\adb-path.txt。缺少 ADB 不影响其他工具使用。
8. 本版用隔离的模拟设备程序验证 ADB 命令与传输流程，预览中的 DEMO 设备为模拟数据；
   未对真实设备执行 Shell 或文件传输。真实权限、USB 驱动和设备兼容性仍需实际确认。
9. 板端浏览使用普通 Shell 权限，只读一层目录，要求设备提供兼容 POSIX 的 Shell。
   单次最多列出前 1,000 项，超出时会提示；筛选/补全只覆盖当前已读取的条目，不递归扫描设备。
   权限不足、断线或数据不完整时清空旧列表并禁用选择，不会当成空目录；关闭窗口会取消读取。
   无效链接、特殊文件不支持选择；含控制字符或无效 UTF-8 的名称会跳过并提示。

开发验证
运行 Toolbox.exe --self-test，会启动临时本地 HTTP 服务器，验证直连、显式代理转发、
下载计时、取消、流停顿取消、错误状态和网页拒绝，结果写入程序旁的 self-test.txt。
同时验证 IP 风险解析、系统/手动代理请求路由、局域网范围/并发/重试/取消，以及串口编码、分片接收、
日志上限、发送串行化、TCP/UDP 回环、定向/群发、端口释放和异常清理。串口测试使用模拟对象，不打开真实 COM 端口。
系统代理测试只临时修改测试进程的默认代理，结束后恢复，不修改 Windows 设置。
运行 tests/run.cmd，验证本页连接方式切换、参数展开收起、单按钮连接/断开、
设置锁定、单条/多条模拟收发、循环顺序、取消、失败中断和退出释放，同时导出窗口预览。界面测试报告和预览位于 bin/test-results/。
抓包测试使用模拟数据，覆盖协议解析与 10,000 组畸形输入、PCAP 格式、文件/时长上限、
暂停、列表裁剪后文件完整性、异常清理和退出等待，不打开真实网卡。
运行 Toolbox.exe --smoke-test，会打开并关闭界面，将界面预览写入程序旁的 preview.png。
运行 Toolbox.exe --check-universities，会使用直连分别对两所大学进行两秒下载测试，
结果写入 university-test.txt。该命令会消耗实际网络流量。
运行 Toolbox.exe --check-ip，会实际查询当前直连出口及对应的 Scamalytics 风险分，
验证结果写入 ip-test.txt，报告不记录具体公网 IP。
运行 Toolbox.exe --check-lan，只对本机 127.0.0.1 进行原生 Ping 验证，
结果写入 lan-test.txt，不自动扫描整个局域网。

打包与发布
构建后在 Windows PowerShell 中执行 .\package.ps1 -Version 3.3.0，生成
bin/Toolbox-3.3.0-portable.zip 和对应 .zip.sha256。ZIP 包含 EXE、说明以及完整官方 Platform Tools，
保留 SDK 的 DLL 和 NOTICE；下载地址、版本和 SHA256 固定，不包含测试文件、本机设置或 Npcap 驱动。
推送 v3.3.0 形式的版本标签会触发 GitHub Actions：Windows 构建、核心测试、界面测试、打包、发布。
Release 上传完整 ZIP 和校验文件，不只是单个 EXE。也可在 Actions 手动指定已存在的版本标签。
已有 Release 不覆盖，修订时使用新版本标签；源码仓库不提交二进制和编译中间产物。

代码组织
保持现有 WinForms / .NET Framework 4.8 单 EXE 结构；抓包调用系统安装的 Npcap，ADB 调用官方工具。
导航统一管理功能页与操作按钮；串口布局、事件绑定、通信和字节编码各有明确职责。
直接复用原有网络功能，避免为这版新增通用插件框架或重复封装。
